# Dragon Chess (WoW Classic addon)

A free, real-time match-3 puzzle with RPG combat against Classic bosses, playable in a window inside World of Warcraft.
Swap gems to match colours, charge skill and ult gems, and take down Classic enemies before they take you down.

## Install

1. Download `DragonChess-<version>.zip` from the [Releases](../../releases) page.
2. Unzip it so that the folder `DragonChess` ends up in `World of Warcraft/<client>/Interface/AddOns/`.
3. In game: `/dchess` (or the minimap button).

`/dchess debug` opens a developer panel (fights, board cheats, effects, sounds, enemy model tuning).

## Notes

- The addon only references assets that ship with the WoW client by path; nothing from Blizzard is included here.
