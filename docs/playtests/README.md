# Playtest log

One file per session: `YYYY-MM-DD-<build-or-milestone>.md`. Short and honest; this is where fun
and feel get decided (specs don't decide them). Agents read these before proposing design changes.

```markdown
# Playtest YYYY-MM-DD — <milestone / build (commit)>

- Who / how long / difficulty / runs played:
- Felt good:
- Felt bad or confusing:
- Bugs seen:
- Numbers (optional): run length, where runs ended, win/lose
- Decisions taken: (→ copy to ROADMAP decisions log)
- Follow-ups: (→ new ids, e.g. M1-G2.1)
```
